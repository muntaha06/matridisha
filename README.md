# MatriDisha Project Setup Guide

## Requirements
- SQL Server
- SQL Server Management Studio
- Java 17+
- VS Code

## Database Setup
1. Open SSMS
2. Click New Query
3. Run setup_database.sql

## Login Details
Username: projectuser
Password: Project@123

## Run Project
1. Open project in VS Code
2. Run MainApp.java
3. Open browser: http://localhost:8081
